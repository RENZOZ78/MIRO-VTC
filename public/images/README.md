# Photos du site

Déposer ici les photos ; le site les utilise automatiquement dès qu'elles existent
(sinon il affiche ses dégradés et son illustration). Noms attendus (voir `src/lib/images.ts`) :

| Fichier | Usage | Format conseillé |
| --- | --- | --- |
| `hero.jpg` | Accueil, arrière-plan du bandeau | 16:9, ≥ 1920 px de large |
| `interieur.jpg` | Section flotte (habitacle) | 3:2, ≥ 1600 px |
| `aeroport.jpg` | Services / transferts aéroport | 3:2, ≥ 1600 px |
| `entreprises.jpg` | Page Entreprises | 16:9, ≥ 1920 px |

Conseil : exporter en JPEG qualité 80, ou en WebP. Les vraies photos des véhicules
(sans plaque lisible) sont préférables aux images générées.
